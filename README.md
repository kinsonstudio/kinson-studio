## 🎯 项目简介

Kinson Studio 是一款面向普通用户的**一站式文件处理工具**，将格式转换、OCR 文字识别、压缩解压、加密音乐解密等常用功能整合在一个简洁优雅的界面中。无需复杂配置，拖入文件即可处理，让每个人都能轻松搞定文件格式问题。

## ✨ 功能特性

### 🖼️ 图片转换
支持 JPG / PNG / WebP / GIF / BMP / TIFF / AVIF / ICO / HEIC 等格式互转，**批量处理**，画质无损。支持**多张图片合并为 PDF**。

### 🎵 音频转换
MP3 / WAV / FLAC / M4A / AAC / OGG / Opus / WMA 格式互转，支持 320kbps 高品质输出，批量转换。

### 🎬 视频转换
MP4 / MOV / MKV / WebM / AVI / M4V / WMV / FLV 格式互转，硬件加速，快速高效，批量处理。

### 📄 文档转换
Word / Excel / PPT / PDF / TXT / HTML / Markdown / EPUB 格式互转，按需下载 LibreOffice，不占空间。

### 🔍 OCR 文字识别
中英文混合识别，**微信式提取文字**——识别后图片上的文字可直接滑动选中、右键复制，就像在微信里提取文字一样自然。

### 🗜️ 压缩解压
ZIP 格式压缩与解压，支持**批量压缩**、**批量解压**，操作简单，一键完成。

### 🔓 加密音乐解密
支持网易云 NCM、QQ 音乐 QMC、酷狗 KGM 等加密格式解密，还原原始音频。
