
# Kinson Studio 🎧

一款永久免费、无水印、不限次数的全能格式转换器。

## ✨ 功能特性

- 🖼️ **图片转换**：JPG / PNG / WebP / GIF / BMP / TIFF / AVIF / ICO / HEIC / RAW
- 🎵 **音频转换**：MP3 / WAV / FLAC / M4A / AAC / OGG / Opus / WMA
- 🎬 **视频转换**：MP4 / MOV / MKV / WebM / AVI / M4V / WMV / FLV
- 📄 **文档转换**：Word / Excel / PPT / PDF / TXT / HTML / Markdown / EPUB（需下载 LibreOffice）
- 🔓 **加密音乐解密**：NCM / QMC / KGM / KGG
- 📦 **压缩解压**：ZIP
- 🔍 **OCR 文字识别**：中英文识别，微信式提取文字，滑动选中即可复制
